# 🔐 SecureLoginApp

## 📌 Project Overview

SecureLoginApp is a secure web authentication application developed using Node.js, Express.js, HTML, CSS, JavaScript, and IBM Cloud App ID.

The project demonstrates how secure user authentication and protected access can be implemented in a web application using cloud-based identity management.

## ✨ Features

- 🔐 Secure user authentication
- 👤 Login and logout functionality
- 🛡️ Protected dashboard
- 🔑 Session-based authentication
- ☁️ IBM Cloud App ID integration
- 🌐 Express.js backend
- 📱 Responsive web interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- IBM Cloud App ID

## 📂 Project Structure

| File | Description |
|---|---|
